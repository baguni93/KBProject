========================================
📌 Git Commit Convention
========================================

형식
----------------------------------------
<type>(<scope>): <subject>

예시
feat(feed): 피드 생성 API 구현
fix(api): 친구 목록 조회 오류 수정
refactor(store): 사용자 상태 관리 개선


========================================
📌 Type
========================================

feat      : 새로운 기능 추가
fix       : 버그 수정
refactor  : 리팩토링 (기능 변경 없음)
style     : 코드 스타일 변경 (포맷팅, 공백 등)
docs      : 문서 수정
test      : 테스트 코드 추가 및 수정
chore     : 설정, 의존성, 빌드 관련
perf      : 성능 개선
build     : 빌드 관련 변경
ci        : CI/CD 설정
revert    : 이전 커밋 되돌리기


========================================
📌 Scope
========================================

[Frontend]

frontend  : 프론트엔드 전체
ui        : UI
page      : 페이지
component : 컴포넌트
router    : 라우터
store     : Pinia / Vuex
api       : API 호출
auth      : 로그인 / 인증


[Backend]

backend      : 백엔드 전체
user         : 회원
friend       : 친구
wallet       : 지갑
transaction  : 거래
settlement   : 정산
feed         : 피드
notification : 알림
event        : 이벤트
card         : 카드
security     : 인증 / 인가
db           : DB / MyBatis


[Common]

common  : 공통 기능
config  : 설정
deploy  : 배포
docs    : 문서


========================================
📌 Frontend 예시
========================================

feat(frontend): 로그인 화면 구현
feat(component): 정산 카드 컴포넌트 추가
fix(api): 친구 목록 조회 오류 수정
fix(router): 로그인 리다이렉트 수정
refactor(store): 사용자 상태 관리 개선
style(ui): 버튼 스타일 통일


========================================
📌 Backend 예시
========================================

feat(feed): 피드 생성 API 구현
feat(friend): 친구 요청 API 추가
feat(settlement): 정산 생성 API 구현
feat(notification): 리마인드 알림 추가

fix(feed): 피드 조회 NPE 수정
fix(wallet): 송금 금액 검증 오류 수정

refactor(feed): FeedService 책임 분리
refactor(transaction): 거래 생성 로직 개선

test(settlement): 정산 서비스 테스트 추가

chore(config): application.properties 수정


========================================
📌 Frontend + Backend 함께 작업
========================================

권장 ① (기능별로 하나의 커밋)

feat(common): 친구 요청 기능 구현
feat(common): 정산 생성 기능 구현
fix(common): 로그인 토큰 갱신 오류 수정


권장 ② (프론트/백엔드 분리 커밋)

feat(frontend): 친구 요청 화면 추가
feat(friend): 친구 요청 API 구현


========================================
📌 Commit 작성 규칙
========================================

✔ 제목은 50자 이내
✔ 현재형으로 작성 (추가, 수정, 구현)
✔ 마침표(.) 사용 금지
✔ 하나의 커밋에는 하나의 작업만 포함
✔ 가능하면 Frontend / Backend 커밋 분리
✔ Front + Back 동시 작업 시 common Scope 사용
